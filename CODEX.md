# Suvadu Codex Entry Point

Codex agents must use `AGENTS.md` as the canonical operating contract for this repository.
`CLAUDE.md` is kept byte-identical with `AGENTS.md` for Claude Code.

This file exists only so agents and humans looking for a Codex-specific entry point find the
right source — it is not a third, divergent rules file.

Before substantive work, read: `STATUS.md`, `CHECKPOINT.md`, `tasks/atomic-task-list.md`,
`docs/RUNBOOK.md`, `docs/REPRODUCIBILITY.md`, `docs/DECISION_LOG.md`,
`docs/RISKS_AND_OPEN_QUESTIONS.md`, and the append-only files under `notes/`.

Note: `STATUS.md`, `CHECKPOINT.md` and `notes/` are gitignored (this repo is public) and exist
only in the local working tree. If they are absent, you are working from a fresh clone and must
ask the maintainer for the current state rather than inferring it.

Do not treat this file as a substitute for `AGENTS.md`.
